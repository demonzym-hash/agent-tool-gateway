# Commercial Licensing

Agent Tool Gateway uses a dual-license model:

- Public core edition: GNU Affero General Public License v3.0 only (`AGPL-3.0-only`).
- Commercial license: available separately from the project owner.

The AGPL public license allows commercial use, modification, distribution, and network service deployment, as long as the user complies with the AGPL terms. In particular, modified network-service versions must offer corresponding source code to users who interact with the service over a network.

Organizations that do not want AGPL obligations can buy a commercial license.

## When A Commercial License Is Useful

A commercial license is intended for organizations that want to:

- embed ATG into a proprietary or closed-source product;
- offer a modified ATG-based SaaS, managed service, or customer deployment without releasing the corresponding source code under AGPL;
- redistribute ATG as part of a commercial platform under non-AGPL terms;
- receive enterprise features, private builds, SLA-backed support, or private deployment help;
- obtain written commercial terms for procurement, compliance, OEM, or reseller use.

## Public Edition Boundary

The public edition focuses on the core Agent-to-HTTP-Tool governance loop:

- Agent identity and API keys;
- Tool registry and invocation gateway;
- allow, deny, approve, and redact policies;
- approval flow;
- redaction and credential isolation;
- audit logs and evidence APIs;
- Web Console;
- OpenAPI, Dify, MCP, Python SDK, and TypeScript SDK examples.

Potential commercial or enterprise capabilities may include:

- SSO/OIDC and enterprise RBAC;
- teams, tenants, and organization controls;
- high availability deployment patterns;
- Vault/KMS/SIEM integrations;
- enterprise approval workflow integrations;
- long-term audit retention, export, and compliance reporting;
- commercial support, migration support, private deployment help, and SLAs.
